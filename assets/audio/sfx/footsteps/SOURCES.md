# Footstep Audio Assets - CC0 1.0 Universal

All 20 WAV files in this directory are procedurally synthesised and carry
no rights - released under CC0 1.0 Universal (Public Domain).

## Files
- footstep_grass_walk_000-004.wav  (organic turf thud + leaf blade crunch)
- footstep_grass_run_000-004.wav   (heavier impact + multi-burst crunch + rustle)
- footstep_dirt_walk_000-004.wav   (earthy heel thump + grit scuff)
- footstep_dirt_run_000-004.wav    (punchy thump + heavy scuff + kickup)

## Synthesis
PCM 44100 Hz, 16-bit Mono, synthesised in PowerShell using:
- Frequency-swept sine oscillator (thud body, 95-140 Hz -> 50-75 Hz)
- Bandpass-filtered white noise (crunch/grit texture)
- Soft-tanh saturation (warmth)
