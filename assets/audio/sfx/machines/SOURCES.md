# Machine Sound Effects (SFX)

License: Creative Commons Zero (CC0 1.0 Universal) - Public Domain Dedication.

## Files
- `machine_furnace_loop.wav`: Warm fire rumble and crackling flame loop for the smelting furnace.
- `machine_preserves_loop.wav`: Simmering liquid and bubbling loop for the Preserves Jar.
- `machine_dehydrator_loop.wav`: Warm airflow blower and motor hum loop for the Dehydrator.
- `machine_start.wav`: Mechanical latch and engagement sound when a process starts.
- `machine_ready.wav`: Clean bell chime indicating an artisan product is ready for collection.
- `machine_mayonnaise_loop.wav`: Soft motor and stirring rhythm for the mayonnaise maker.
- `machine_cheese_loop.wav`: Low wooden/mechanical compression pulses for the cheese press.
- `machine_loom_loop.wav`: Alternating shuttle/clack rhythm for the loom.

All audio files in this directory are procedurally generated and free for use in any project without attribution required.
