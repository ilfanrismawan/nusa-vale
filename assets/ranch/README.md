# Aset tambahan peternakan

SVG 16×16: `milk_pail`, `shears`, `animal_brush`, `pasture_grass`, dan `dirt`. SVG 32×32: `mayonnaise_maker`.

Tambahan interior: `feeding_trough` (48×16), `nesting_box` (32×16), `care_board` (32×32), dan `water_basin` (16×16). Palung, sarang, papan, dan wadah air memakai palet kayu/cokelat dan jerami/krem yang sama.

Dibuat khusus untuk Nusa Vale pada 13 Oktober 2026 sebagai aset piksel dengan palet cokelat, krem, dan hijau yang selaras dengan aset ladang. `shape-rendering="crispEdges"` dan filter Nearest menjaga batas piksel. File dapat diedit sebagai vektor; Godot mengimpornya sebagai tekstur game.

Sprite `assets/farm_rpg/animals/cow.png`, `goat.png`, `sheep.png`, dan `duck.png` disalin dari Farm RPG Tiny Asset Pack milik pengguna: folder Animals/Farm, varian sapi betina hitam, kambing betina cokelat, domba betina, dan bebek putih. Lisensi paket asli tetap berlaku pada aset tersebut.
