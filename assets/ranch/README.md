# Aset tambahan peternakan

Ikon 16×16: `milk_pail`, `shears`, `animal_brush`, `pasture_grass`, dan `dirt`. Mesin 32×32: `mayonnaise_maker`.

Tambahan interior: `feeding_trough` (48×16), `nesting_box` (32×16), `care_board` (32×32), dan `water_basin` (16×16).

Sumber digambar ulang di Aseprite pada 28 Oktober 2026 (`*.aseprite`, ekspor PNG bernama sama) mengikuti gaya Farm RPG Tiny Asset Pack: outline gelap 1 px, bayangan datar 3–4 nada, cahaya dari kiri atas. Palet kayu cokelat, jerami kuning, logam abu-biru, dan hijau rumput dipakai bersama. `buffalo_cheese` juga punya sumber `.aseprite` (nada krem hangat dan simpul mozarela). File `.svg` lama tidak lagi dirujuk game dan hanya disimpan sebagai riwayat (masih dipakai pratinjau di `scratch/eep-art-preview`).

Sprite ternak di game diambil langsung dari folder paket Farm RPG Tiny Asset Pack (lihat `scripts/ui/ranch_visual.gd`): `animals/Farm` (ayam, bebek, sapi, kambing, domba, kuda padang, termasuk sheet anaknya), `animals/Forest/Capybara`, dan ikon hewan peliharaan dari `animals/Pets`. Kerbau tidak ada di paket, jadi tetap memakai `animals/buffalo.png`. Kuda tunggangan memakai `Character/PNG/14.x Horse` agar sinkron dengan animasi pemain. Lisensi paket asli tetap berlaku.
