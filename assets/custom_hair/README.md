# Korean Curtain

Source artwork: `korean_curtain.png`, generated with built-in imagegen.
Prompt: hair-only transparent pixel art sheet; Korean center-part curtain
haircut, rounded black wavy crown, two swept fringe sections, tapered sides
and nape; front, back, right and left views; no face, text or body.

Select **Korean Curtain** in character customization. Four colors are supported:
black, blonde, brown and ginger. `CharacterHairStyler` draws the native 32px
adaptation using each animation frame's head anchor and hair palette. This
keeps the face aligned when walking, running, using tools, fishing or sleeping.
The catalog links the source artwork via `design_source`. Runtime masks are
drawn before face accessories and hats, using the existing animation timing.
