# Audit stabilisasi dan cooking — 14 Oktober 2026

Audit menggunakan kode, Resource, scene runtime, input simulasi dan runner
Godot headless. Hasil ini tidak menyatakan seluruh game bebas bug dan tidak
menggantikan playtest visual, suara, gamepad fisik atau tujuh hari bermain.

## Bug yang diperbaiki

- Interaksi kasur mengalami parse error karena tipe koordinat mouse tidak
  eksplisit. Klik kanan di area kasur sekarang menggunakan jalur player,
  termasuk routing input HUD; input co-op menerima aksi interaksi.
- Angkat hewan sempat menggantikan seluruh perawatan dan penurunan ikut
  mengelus/memanen. Perawatan klik kanan tetap tersedia; angkat dengan
  klik kiri pada slot kosong atau tahan tombol lari + interaksi. Interaksi
  atau klik kiri saat membawa menurunkan hewan tanpa transaksi inventory.
- Membawa hewan mempertahankan node dan identitas kandang, mencegah pemain
  lain mengambil hewan yang sama, menghentikan roaming, dan menempatkan
  sprite di atas karakter. Refresh kandang tidak mereset pose carry.
- Perpindahan area melepaskan hewan sebelum travel. Penurunan dibatasi
  interior dan memeriksa rintangan; perawatan/produk tidak berubah.
- `get_meta` dengan default null mengeluarkan error saat belum ada hewan
  yang dibawa. Pengecekan metadata sekarang mendahului pembacaan.
- Resolusi tersimpan tertimpa dropdown lama saat load. Pilihan resolusi
  diselaraskan; fullscreen eksklusif dan fullscreen tanpa bingkai dipetakan
  dengan benar. `stretch/scale_mode` memakai nilai valid `fractional`.
- Runner membaca output sampai EOF sebelum membunuh proses timeout, sehingga
  timeout bisa ikut macet. Proses milik runner kini dihentikan dahulu.
- Refresh semua sheet setiap pickup dibuang karena mahal dan bukan solusi
  sumber atlas. Tes animasi memastikan semua frame memakai ImageTexture
  hasil komposisi, termasuk gesture dan locomotion; 188 animasi diperiksa.
- Drag klik kiri placement sekarang menunggu release: klik singkat memasang,
  gerakan di atas ambang 6 px menggeser kamera tanpa memasang. Tepi layar,
  tombol arah, middle drag, zoom dan batas kamera tetap tersedia.
- Autoload cheat dihapus dari runtime. Preset mengecualikan script cheat,
  tests, tools, scratch dan cadangan. Shortcut waktu/co-op serta override
  fishing dibatasi ke editor, termasuk pada template debug yang diexport.
- Dua icon ikan lama memiliki UID texture invalid; referensi UID dihapus
  agar path yang memang dipakai tidak lagi mengeluarkan warning. Gambar
  placeholder ikan legacy masih perlu diganti dengan art yang sesuai.

## Kelanjutan GDD

Cooking dasar telah dimulai dengan lima resep, buku resep per pemain,
inventory aman, makanan pemulih stamina dan buff laju sementara. Batas
implementasi dan kontrol dijelaskan di `COOKING.md`. Cooking lengkap,
combat/HP, dapur rumah, dan sosial belum dinyatakan selesai.

## Bukti

Full suite `verify_mvp.ps1` lulus: `scratch/audit-verified-suite.log`.
Log fokus tersedia di `scratch/audit-controls-cooking.log`,
`scratch/audit-carry-final.log`, dan `scratch/audit-new-features.log`.
Setelah full suite, handler drag diperbaiki agar klik tombol UI tidak
terserap; regresi placement diulang dan lulus di
`scratch/audit-placement-buttons.log`, termasuk klik tombol cancel.
Error I/O dalam tes save/Balai merupakan injeksi kegagalan yang disengaja;
run berakhir `MVP verification passed.` tanpa assertion gagal.

Export resource pack berhasil (24.821.860 byte). Inspeksi dari direktori
terisolasi selesai `EXPORT CONTENT AUDIT COMPLETE: failures=0` di
`scratch/audit-export-content-final.log`: script cheat, tes, tools dan
autoload DebugManager tidak ada; kelima data/icon makanan terbaca.
Paket ini digunakan untuk audit isi; build Web belum dimainkan di browser.

Inspeksi awal dari cwd proyek memberikan hasil palsu karena resource Godot
dapat membaca file source lokal di luar pack. Inspeksi final menggunakan
cwd/`--path` sementara sehingga hanya resource dalam pack yang diuji.
